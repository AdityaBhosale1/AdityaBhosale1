# 🚗 ABRIS System – CNG Range Extended Electric Vehicle

## 🚀 About the Project
ABRIS (Automatic Battery Rest & Isolation System) is a hardware-based solution designed to improve the efficiency and lifespan of electric vehicles.

The system uses a **CNG generator** to supply power when the battery is under heavy load, while temporarily isolating the battery to allow cooling and recovery.

## 🏆 Achievement
- 🎯 Top 10 Finalist – Tata Technologies INNOVENT Hackathon
- 💡 Innovative EV solution for real-world application

## ⚙️ How It Works
1. Battery level decreases or load increases  
2. ABRIS activates CNG generator  
3. Battery is isolated (rest mode)  
4. Generator supplies power to vehicle  
5. Battery reconnects after safe level  

## 🔧 Hardware Components
- Microcontroller (Arduino / ESP32)  
- CNG Engine & Generator  
- Battery Pack  
- Sensors (Temperature, Voltage)  
- Relay Module  
- Power Electronics
